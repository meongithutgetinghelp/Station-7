🚉 Station 7

Not every passenger belongs here.

Station 7 is a cooperative psychological horror game set inside an isolated train station. What begins as an ordinary night shift gradually turns into something much more disturbing.

Players work together to keep the station running by completing routine tasks, checking passengers, maintaining equipment, and watching for anything unusual.

But as the nights progress, the station becomes increasingly unpredictable. Something is hiding among the passengers, and not everything is what it appears to be.

🎮 Overview

Genre: Cooperative Horror / Psychological Horror

Engine: Godot 4.7.2

Platform: PC (planned)

Multiplayer: Cooperative multiplayer

Players: 4 players

👁️ Features

Cooperative gameplay focused on teamwork.

Routine station-management tasks.

Unsettling environmental events and encounters.

A mysterious entity capable of disguising itself.

Progressively more dangerous night shifts.

Atmosphere built around suspense, uncertainty, and paranoia.

Features listed here should be updated as development progresses.

🌙 Gameplay

The game is structured around a series of night shifts.

Early Nights

Players perform ordinary station duties, learning the environment and establishing their routine.

Later Nights

Strange occurrences become harder to ignore. Players must pay closer attention to passengers, objects, and their surroundings while dealing with increasingly dangerous situations.

🛠️ Development

Station 7 is an independently developed project built using Godot Engine 4.7.2.

The game is currently under development. Features, mechanics, and content may change throughout development.

🚀 Running the Project

Install Godot Engine.

Clone or download this repository.

Open Godot's Project Manager.

Select Import.

Locate the project's project.godot file.

Open the project and run it.

📁 Repository Structure

The project contains the game's scenes, scripts, assets, resources, and configuration files.
